HTTP 0.9, 1.0, and 1.1

HTTP/0.9

The first HTTP version was very simple. The HTTP Request header was one line and contained one method, GET. The response only contained the HTML document. Unlike later HTTP versions, the connection was terminated after the request gets sent.

HTTP/1.0

The HTTP request now contained the HTTP version and status code. HTTP became more versatile as hypermedia can be sent and not just hypertext documents. New HTTP headers and methods were introduced.

HTTP/1.1

With continuous development in HTTP versions, HTTP 1.1 was officially standardized. It introduced the keepalive connection, where the connection between the client and server no longer closed after every request. It remained opened, allowing the user to use the same connection to send more requests.
