Evolution of HTTP

Introduction

Hypertext Transfer Protocol (HTTP) was developed by Tim Berner-Lee along with his invention of the World Wide Web. HTTP is the rules of communication between computers on the internet.

Key Terms

HTTP HTTP is a protocol used for transferring hypermedia documents through web browsers.
World Wide Web The World Wide Web is the global system of connected webpages, documents, and media on the internet.
Protocol Protocols are the set of rules and instructions to carry out a task.
Web Browser Web browsers are an application that lets users access, view, and interact with webpages.
