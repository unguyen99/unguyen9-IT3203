Key Concepts

HTTP Request A client makes an HTTP request to the server. The HTTP request is a message asking the server to retrieve data.
HTTP Response The server sends an HTTP response to the client after receiving the HTTP request. The HTTP response contains the data requested by the client.
Client A client is the device that sends the request. Web browsers are clients.
Server A server is the device that holds and retrieves data. Web servers are the servers.
HTTP Status Code HTTP status codes describe if the HTTP request was successful or not. Status codes 400-499 indicate client error while 500-599 indicate server error.
