HTTP 2 and HTTP 3

HTTP/2

Websites increased in complexity and more users visited websites over time. Google worked on a project, SPDY, a procotol which eventually developed into HTTP/2. The IETF published HTTP/2 as RFC 7540 in 2015. HTTP/2 increased optimization by using a binary format instead of the previously used plaintext. HTTP/2 was easily adoptable by websites transitioning from HTTP/1.1 to HTTP/2 as no major changes were required. However, HTTP/2 introduced a problem where a lost packet can hold up other requests on the connection.

HTTP/3

HTTP/3 focuses on improving HTTP/2's security and performance. HTTP/3 was based on the QUIC protocol which was also developed by Google. The IETF published QUIC as RFC 9000. Quic is built on top of UDP (User Datagram Protocol). HTTP/3 uses binary instead of decimal to transmit data.
