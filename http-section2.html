HTTP 2 and HTTP 3

HTTP/2

Websites increased in complexity and more users visited websites over time. Google worked on a project, SPDY, which eventually developed into HTTP/2. HTTP/2 increased optimization by using a binary format instead of the previously used plaintext. HTTP/2 was easily adoptable by websites transitioning from HTTP/1.1 to HTTP/2 as no major changes were required.

HTTP/3

HTTP/3 focuses on improving HTTP/2's security and performance. HTTP/3 was based on the QUIC protocol which was also developed by Google.
